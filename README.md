# Архитектурное соответствие файлов программной реализации

Реализация следует иерархии ERP → MES/SCADA → оборудование участка (ГОСТ Р МЭК 62264). Участок: токарная обработка, фрезерная обработка, закалка.

## Уровень оборудования участка (объект управления)

- `plant.py` — цифровой двойник участка. Метод `Plant.evolve` задаёт динамику 8 технологических показателей x₁–x₈ (токарная обработка: x₁–x₃, фрезерная обработка: x₄–x₆, закалка: x₇–x₈) и отклик на управляющее воздействие.
- `scenarios.py` — особые причины изменчивости (износ инструмента, вибрация, недостаточное охлаждение), действующие на объект.
- `labels.py` — описание показателей и их привязка к операциям.

## Уровень MES/SCADA

- **Нормализация, критериальная свёртка, карта Шухарта X–MR.** Реализованы в `plant.py`: калибровка границ UCL/LCL по X–MR (`_calibrate_control_charts`), нормализация (`normalize`), весовые коэффициенты (`_compute_weights`), суперкритерий (`compute_super_criterion`), зональные критерии (`zone_criteria`). Построение карты X–MR — `gui/plots.py` (`ChartPlot`).
- **Сумматор.** Формирование рассогласования ε = g − K в цикле `run_episode` (`episode.py`).
- **Регулятор прямого контура (CNN).** Архитектура — `model.py`, применение в контуре — `episode.py` (`CNNPolicy`, `build_features`), обучение — `trainer.py` и `workers.py`. ПИД-регулятор (`PIDPolicy`) служит учителем для генерации обучающей выборки.
- **Оценка качества и визуализация.** `metrics.py` (Ts, IAE, доля тактов вне границ), `simulation.py`, `experiment.py`, `visualization.py`.
- **Интерфейс оператора (SCADA/HMI).** `run_gui.py`, `gui/main_window.py`, `gui/plots.py`, `gui/rpms_indicator.py`.

## Уровень ERP

Задаётся параметрами в `config.py`:

- задающее устройство — программное задание суперкритерия `G`;
- производственная программа — веса операций `W_OPS`, `N_GRP`;
- требования к качеству деталей — допустимая полоса `DELTA` и условие завершения `N_CONS`.

## Запуск

- `main.py` — полный вычислительный эксперимент.
- `run_gui.py` — графический интерфейс.
